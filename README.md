# Inventory System

## Project Description

Inventory System is a C# project that manages products and processes customer orders. It checks product stock, calculates the order total, and applies a discount when the order meets the required quantity.

## Tech Stack

* C#
* .NET
* Object-Oriented Programming
* xUnit
* Unit Testing

## Features

* Add and manage products
* Check available stock
* Process customer orders
* Calculate order totals
* Apply quantity discounts
* Return success or error messages

## How to Install and Run

1. Clone this repository.
2. Open the project in Visual Studio.
3. Restore the required .NET packages.
4. Build the solution.
5. Run the application.

### Run the Tests

1. Open the solution in Visual Studio.
2. Open **Test Explorer**.
3. Build the solution.
4. Click **Run All** to run the unit tests.

## Project Structure

The project contains the inventory application and a separate test project for testing the inventory order service.

This project was created as part of my software development studies to practice C#, inventory processing, and unit testing.
